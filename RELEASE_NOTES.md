# ShowDesk 1.1.1

ShowDesk 1.1.1 improves Signal Explorer route separation and highlighted signal tracing.

## Fixes

- Reduce overlapping straight route segments in dense switcher graphs.
- Fade unrelated routes and direction markers while inspecting a signal path, keeping the selected trace clear.

ShowDesk remains read-only: it monitors switcher and HyperDeck state and does not send control commands to either device.
