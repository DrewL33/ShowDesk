# ShowDesk 1.1.4

ShowDesk 1.1.4 streamlines the HyperDeck detail panels.

## Improvements

- Keep only supplemental protocol, transport, and media-slot details in the expandable panels.
- Prevent expanded details from stretching neighboring panels into empty space.

ShowDesk remains read-only: it monitors switcher and HyperDeck state and does not send control commands to either device.
